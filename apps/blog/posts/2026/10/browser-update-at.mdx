### 배경

각각의 브라우저의 버전이 언제 업데이트 되는지에 대해 구체적인 문서를 찾아서 명확히 하고 싶어졌다. 그래서 글로벌하게 점유율이 높은 브라우저의 업데이트 시점 정책에 대해 찾아보았다.

![브라우저 점유율](https://pub-a578dcd164ef4e9fb8b9c1c67f7468ed.r2.dev/posts/2026/10/browser-update-at/image-b87d0aa2-15c0-4d60-a321-850c36391261.webp "모든 디바이스 기준 전세계 브라우저 점유율")

### Chrome&#x20;

전세계적으로 가장 높은 비율로 사용하고 있는 크롬 브라우저는 최신버전이 있다면 자동으로 업데이트 된다 ( Chrome에서 정기적으로 새로운 업데이트가 있는지 확인하고, 사용 가능한 업데이트가 있는 경우 사용자가 브라우저를 닫은 후 다시 열 때 자동으로 적용합된다. - [https://www.google.com/chrome/update/](https://www.google.com/chrome/update/) )&#x20;

업데이트 되면 기존버전 대비 보안적인 기능 향상, 속도, 성능 향상, 새로운 기능을 기대할 수 있다.&#x20;

### Safari

사파리는 OS(운영체제)에 포함되어 있기에 OS 업데이트할때 함께 업데이트 된다. mac은 macOS, iPhone은 iOS, iPad는 iPadOS, Apple vision Pro 는 visionOS 각각의 기기별로 업데이트 하면된다.

[https://support.apple.com/ko-kr/102665](https://support.apple.com/ko-kr/102665)

### Edge&#x20;

기본적으로 Edge도 크롬처럼 자동으로 업데이트 된다.

다만 2가지 예외 상황일때만 수동 업데이트 한다고 되어있으며 해당 경우는 진짜 좀 특별한 경우인데 데이터 제한이 걸려있고 업데이트 버전을 위해 다운로드해야 될때 대규모 데이터가 필요한 경우로 생각하면 될 것 같다. ( 매우 특별한 상황이며 구체적인 상황에 대한 자세한 내용은 [https://support.microsoft.com/ko-kr/edge/microsoft-edge-update-settings](https://support.microsoft.com/ko-kr/edge/microsoft-edge-update-settings) 를 확인해보자 )&#x20;

### FireFox

파이어 폭스도 자동으로 업데이트가 기본이며 사용자가 사용중에 백그라운드에서 자동으로 새버전을 다운로드하고 새로 브라우저를 시작할때 자동으로 새버전이 적용된다. ( 의도적으로 업데이트 설정을 변경할 수 있다 )

[https://support.mozilla.org/ko/kb/update-firefox-latest-release](https://support.mozilla.org/ko/kb/update-firefox-latest-release)

### Samsung Internet

삼성인터넷은 좀 특이하다 찾아보니 심각한 버그 수정이나 보안 업데이트 같은 중요한 업데이트는 자동으로 일어나고 ( [https://www.internet.apps.samsung.com/pt/index.html?type\=tos\&version\=3.2.0\&country\=KR\&language\=ko](https://www.internet.apps.samsung.com/pt/index.html?type=tos\&version=3.2.0\&country=KR\&language=ko) ) 그 외 일반적인 신기능 추가나 개선 사항 등은 사용자의 별도 동의나 수동 업데이트 과정으로 거치도록 되어 있었다.

수동 업데이트 같은 경우 사용자가 직접 앱 마켓(구글 플레이 스토어, 갤럭시 스토어 )에 들어가서 업데이트 버튼을 눌러야 한다고 한다. ( [https://www.samsung.com/levant/support/apps-services/install-or-update-samsung-internet/](https://www.samsung.com/levant/support/apps-services/install-or-update-samsung-internet/) )

### 최신 브라우저를 쓰자

당연한 애기긴 하지만 각 브라우저 새버전의 경우 보안 업데이트, 새로운 기능 업데이트, 속도, 성능의 업데이트로 인해 기존 브라우저 대비 이점을 가져갈 수 있으니 웬만하면 최신버전으로 가져가는게 좋다. 다른 이점들은 차치하더라도 특히 보안은 매우 크리티컬한 요소이기 때문에 중요하다.&#x20;
